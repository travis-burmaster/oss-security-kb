# Proposed OSS KB Update: `react-server-dom-webpack` (npm)

## Recommendation

**Create a new dedicated KB page** for the npm package `react-server-dom-webpack`.

### Justification

1. **Significant vulnerability surface**: Six distinct CVEs spanning CRITICAL, HIGH, and MODERATE severity have been publicly disclosed against this package, all within a concentrated timeframe.
2. **Wide adoption impact**: This package is part of the React framework's server-components ecosystem and is used by major meta-frameworks (Next.js App Router, etc.). Its exposure footprint is substantial.
3. **Actionable fixed versions exist**: All six vulnerabilities have confirmed patches across multiple release lines (19.0.x, 19.1.x, 19.2.x), making version-pinning guidance valuable.
4. **Distinct from the core `react` package page**: The vulnerabilities are scoped specifically to the React Server Components flight protocol layer (serialization/deserialization), not the general React DOM runtime. A separate page avoids conflating unrelated advisories.

### Key Notes

- **Minimum safe versions**: Users should upgrade to at least **19.0.5 / 19.1.6 / 19.2.5** to cover all six advisories.
- **Shared blog post**: Meta published a consolidated disclosure at https://react.dev/blog/2025/12/11/denial-of-service-and-source-code-exposure-in-react-server-components covering the DoS and source-code-exposure class.
- **RCE (CVE-2025-55182)** has linked public fix references in the advisory. Prioritize this patch above all others.
- **Sibling packages affected**: The same advisories apply to `react-server-dom-esm` and potentially other `react-server-dom-*` variants; cross-link if those pages are created.
- **Attack prerequisite context**: All disclosed issues require the application to use React Server Components with the flight wire protocol (i.e., server-rendered RSC payloads consumed by a client). Traditional client-only React apps are not affected.
