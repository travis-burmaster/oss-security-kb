# Proposed KB Page: `org.apache.logging.log4j:log4j-core`

---

## 1. Overview

| Field | Value |
|---|---|
| **Package** | `org.apache.logging.log4j:log4j-core` |
| **Ecosystem** | Maven (Java) |
| **Project** | Apache Log4j 2 |
| **Repository** | https://github.com/apache/logging-log4j2 |
| **Upstream Security Page** | https://logging.apache.org/log4j/2.x/security.html |
| **VDR (CycloneDX)** | https://logging.apache.org/cyclonedx/vdr.xml |

**Scope note:** Only `log4j-core` is in scope. The sibling artifact `log4j-api` is not directly affected by the vulnerabilities listed below but should be kept version-aligned per upstream guidance. Third-party repackages (e.g., `org.ops4j.pax.logging:pax-logging-log4j2`, `com.guicedee.services:log4j-core`) have their own fix versions and are noted only where the evidence explicitly mentions them.
