# FastAPI OSS Security KB — Proposed Update

## Recommended Page Status

**ACTIVE** — Two distinct confirmed vulnerabilities affecting the `fastapi` PyPI package. Evidence is consistent across multiple authoritative sources. No advisories are currently withdrawn that should be treated as live.

## Security Posture Notes

1. **Low advisory count.** FastAPI has only **two confirmed, non-withdrawn CVEs** to date across its entire release history (since 2018). This is a relatively small attack surface for the framework itself.
2. **Dependency-inherited risk.** CVE-2024-24762 is fundamentally a `python-multipart` vulnerability. FastAPI's fix was a minimum-version pin. Organizations should also verify `python-multipart` is updated independently, as it may be installed by other packages (Starlette, etc.).
3. **CSRF fix refinement.** The CVE-2021-32677 fix was partially relaxed in v0.65.3 to accept requests with *no* Content-Type header (assumed JSON), while still blocking explicit `text/plain`. This is a deliberate trade-off between compatibility and strictness — worth noting for security audits.
4. **Maintained project.** Both issues received upstream patches promptly with published security advisories, fix commits, and release notes. Security contact (`security@tiangolo.com`) is documented.
