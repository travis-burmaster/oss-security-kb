# OSS Security KB Page: Maven `org.bouncycastle:bcprov-jdk18on`

## Page Title

**Bouncy Castle Java Provider (bcprov-jdk18on) — Security Advisory Summary**

---

## Concise Risk Themes

| # | Risk Theme | Description |
|---|-----------|-------------|
| 1 | **Timing Side-Channel Attacks** | RSA key exchange and other cryptographic operations vulnerable to timing-based information leakage, potentially enabling key recovery (Marvin Attack variant, covert timing channels). |
| 2 | **Denial of Service (DoS) / Resource Exhaustion** | Crafted inputs (certificates, ASN.1 structures, signatures) trigger infinite loops, excessive CPU usage, or unbounded memory allocation. |
| 3 | **Injection Vulnerabilities (LDAP)** | Insufficient input sanitization in certificate store lookups allows LDAP injection, potentially leading to unauthorized directory queries or data exfiltration. |
| 4 | **DNS Poisoning** | Flawed certificate validation logic susceptible to DNS poisoning during revocation or certificate path checks. |

## Index Summary

> **org.bouncycastle:bcprov-jdk18on** is the Bouncy Castle lightweight cryptography provider for Java (JDK 18+). It has accumulated 9 publicly-disclosed vulnerabilities spanning timing side-channels (including Marvin Attack variants), multiple denial-of-service vectors (infinite loops, CPU/memory exhaustion via malformed certificates and ASN.1 structures), LDAP injection in X.509 certificate store lookups, and DNS poisoning in certificate validation. All known issues are remediated in the current release **1.84**. Projects using versions prior to 1.78 carry the highest aggregate risk. Continuous monitoring is advised given the library's broad role in TLS, certificate handling, and cryptographic primitive implementations across the Java ecosystem.
