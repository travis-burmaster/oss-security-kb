

# OSS Security KB Maintenance Pass — Review & Recommendations

## Methodology

This review is based exclusively on the provided evidence summary, which reflects data gathered from OSV.dev, GitHub Advisory Database (GHSA) references, and existing KB page gap analysis. No external claims are introduced. Recommendations are conservative and grounded in the evidence presented.

## 1. axios — **Immediate KB Refresh Recommended (HIGH PRIORITY)**

### Scope of Gap

The axios KB page is missing **13 distinct, publicly disclosed advisories**, all with `modified` timestamps in the range 2026-05-05 (with one on 2026-04-23-equivalent cadence). Each advisory carries both a GHSA identifier and a unique CVE, confirming they are independently tracked, non-alias vulnerabilities.

### Thematic Clustering of Missing Advisories

To ensure the KB update is structured and not simply a bulk append, the 13 advisories cluster into clear thematic groups:

#### A. Prototype Pollution — Response/Request Integrity (5 advisories)

| GHSA | CVE | Summary |
|---|---|---|
| GHSA-pf86-5x62-jrwf | CVE-2026-42033 | Prototype Pollution Gadgets — Response Tampering, Data Exfiltration, Request Hijacking |
| GHSA-6chq-wfr3-2hj9 | CVE-2026-42035 | Header Injection via Prototype Pollution |
| GHSA-w9j2-pvgh-6h63 | CVE-2026-42041 | Authentication Bypass via Prototype Pollution Gadget in `validateStatus` Merge Strategy |
| GHSA-xx6v-rp6x-q39c | CVE-2026-42042 | XSRF Token Cross-Origin Leakage via Prototype Pollution Gadget in `withXSRFToken` Boolean Coercion |
| GHSA-q8qp-cvcw-x6jj | CVE-2026-42264 | Prototype Pollution Read-Side Gadgets in HTTP Adapter — Credential Injection and Request Hijacking |

**Assessment:** These five represent a coordinated disclosure surface around prototype pollution gadget chains in axios internals. They are **not aliases of each other** — each targets a different code path (`validateStatus`, `withXSRFToken`, HTTP adapter credential handling, header merging, and a general response-tampering vector). All warrant individual entries, though the KB narrative should group them under a common prototype-pollution theme section for clarity.

#### B. Proxy / SSRF Bypass (2 advisories)

| GHSA | CVE | Summary |
|---|---|---|
| GHSA-m7pr-hjqh-92cm | CVE-2026-42038 | `no_proxy` bypass via IP alias allows SSRF |
| GHSA-pmwg-cvhr-8vh7 | CVE-2026-42043 | Incomplete Fix for CVE-2025-62718 — `NO_PROXY` bypassed via RFC 1122 loopback subnet (127.0.0.0/8) in Axios 1.15.0 |

**Assessment:** CVE-2026-42043 explicitly self-identifies as an incomplete fix for a prior CVE (CVE-2025-62718). This is a **distinct advisory, not an alias** — it documents a bypass of a previous patch. Both should be added. The KB should note the fix-bypass lineage.

#### C. Input Validation / Injection (3 advisories)

| GHSA | CVE | Summary |
|---|---|---|
| GHSA-445q-vr5w-6q77 | CVE-2026-42037 | CRLF Injection in multipart/form-data body via unsanitized `blob.type` in `formDataToStream` |
| GHSA-xhjh-pmcv-23jw | CVE-2026-42040 | Null Byte Injection via Reverse-Encoding in `AxiosURLSearchParams` |
| GHSA-3w6x-2g7m-8v23 | CVE-2026-42044 | Invisible JSON Response Tampering via Prototype Pollution Gadget in `parseReviver` |

**Assessment:** Each targets a distinct input surface (multipart blob type, URL search params encoding, JSON parse reviver). All are independent and merit separate entries.

#### D. Resource Limit Bypass / DoS (3 advisories)

| GHSA | CVE | Summary |
|---|---|---|
| GHSA-5c9x-8gcm-mpgx | CVE-2026-42034 | HTTP adapter streamed uploads bypass `maxBodyLength` when `maxRedirects: 0` |
| GHSA-vf2m-468p-8v99 | CVE-2026-42036 | HTTP adapter streamed responses bypass `maxContentLength` |
| GHSA-62hf-57xw-28j9 | CVE-2026-42039 | Unbounded recursion in `toFormData` causes DoS via deeply nested request data |

**Assessment:** CVE-2026-42034 and CVE-2026-42036 both concern streamed transfer size-limit bypasses but target opposite directions (upload vs. download) and different config guards (`maxBodyLength` vs. `maxContentLength`). They are not aliases. CVE-2026-42039 is a distinct recursive DoS vector.

### Recommendation for axios

> **Perform a full KB page refresh.** All 13 advisories are independently identified (unique CVE + unique GHSA), target distinct code paths, and are publicly documented in both OSV.dev and the GitHub Advisory Database. None can be dismissed as alias-only or duplicate. The volume and thematic breadth (prototype pollution gadget chains, SSRF bypasses, injection vectors, resource-limit bypasses) constitute a material change in the package's security profile since the last KB snapshot.

**Suggested KB structure for the update:**
1. Add a "May 2026 Disclosure Batch" section header noting the coordinated timing.
2. Sub-group by theme (Prototype Pollution, Proxy/SSRF, Injection, Resource Limits).
3. For GHSA-pmwg-cvhr-8vh7, explicitly cross-reference the prior CVE-2025-62718 fix it bypasses.
4. Update any "last reviewed" or "advisory count" metadata on the page.
