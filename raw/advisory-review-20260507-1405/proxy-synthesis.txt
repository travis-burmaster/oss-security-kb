* **GHSA-8r3f-844c-mc37 = GO-2024-2611 = CVE-2024-24786** — single record. The GHSA entry lists three affected packages; these are **sub-packages within the same Go module**, not independent libraries. The fix commit (`f01a588e`) and the single release tag `v1.33.0` resolve all three simultaneously because Go modules version at the module root.
* **GHSA-hw7c-3rfg-p46j = GO-2023-1631 = CVE-2023-24535** — single record. Narrow affected window (only v1.29.0).

## 3. Detailed Vulnerability Analysis

### CVE-2024-24786 — protojson Infinite Loop

* **Root Cause:** The JSON decoder in `internal/encoding/json` did not properly detect certain malformed JSON token sequences, causing `protojson.Unmarshal` to loop indefinitely.
* **Attack Vector:** Any service that accepts untrusted JSON and unmarshals it into a protobuf message via `protojson.Unmarshal` or `protojson.UnmarshalOptions.Unmarshal`.
* **Impact:** Denial of service (goroutine hangs forever consuming CPU). No data confidentiality or integrity impact.
* **Fix:** CL 569356 / commit `f01a588e5810b90996452eec4a28f22a0afae023`, released as v1.33.0.
* **Downstream Signal:** Fedora advisory issued; NetApp advisory issued; oss-security disclosure 2024-03-08.

### CVE-2023-24535 — Panic on Crafted Input

* **Root Cause:** Parsing specific crafted protobuf input triggered an unrecovered panic (likely nil dereference or slice bounds check).
* **Attack Vector:** Any service that parses untrusted protobuf wire-format or text-format messages.
* **Impact:** Denial of service (process crash). No data confidentiality or integrity impact.
* **Fix:** CL 475995, released as v1.29.1.
* **Note:** Only v1.29.0 is affected; earlier versions and v1.29.1+ are unaffected.
