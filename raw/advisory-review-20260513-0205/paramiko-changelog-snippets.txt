#973
:
Removed support for the DSA (aka DSS) key algorithm, as it has
been badly outdated and insecure for a decade or more at this point, and was
recently completely removed from OpenSSH as well.
If you were still using DSA out of sheer inertia: we strongly recommend
upgrading to Ed25519 (or maybe ECDSA).
If you were still using DSA because of target hosts you do not control:
please continue using Paramiko 3.x.

:

) Creation

subclasses was subject

exploited by an attacker with knowledge of where the Paramiko-using code

explicit

in place to minimize any possible disruption, though it
may get removed in future backwards-incompatible updates.
Thanks to Jan Schejbal for the report & feedback on the solution, and to
Jeremy Katz at Tidelift for coordinating the disclosure.
