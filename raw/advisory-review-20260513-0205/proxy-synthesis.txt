## Package Summary

Paramiko is a pure-Python implementation of the SSHv2 protocol, providing both client and server functionality. It is widely used for programmatic SSH connections, SFTP transfers, and SSH tunneling. Because it implements the full SSH protocol stack—including key exchange, host-key verification, authentication, and channel multiplexing—its attack surface spans cryptographic primitives, protocol-state machines, and local file operations.
