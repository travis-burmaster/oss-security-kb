## Security Posture Notes

1. **Dominant vulnerability class: Denial of Service.** All 11 CVEs are DoS — either CPU exhaustion (infinite loops) or memory exhaustion (uncontrolled allocation). No RCE, data-leak, or privilege-escalation vulnerabilities are publicly recorded.
2. **Recurring pattern across archive formats.** Affected formats span ZIP, 7Z, TAR, DUMP, Pack200, and BZip2. Every archive format parser has historically had at least one DoS flaw, suggesting that untrusted archive input should always be bounded externally (size limits, timeouts, sandboxing).
3. **Active maintenance.** The project publishes a structured security page, responds promptly with point-fix releases, and follows Apache coordinated disclosure. The security page was updated as recently as 2025-07-26.
4. **Minimum safe version: 1.26.0.** Any deployment processing untrusted archives should be on ≥ 1.26.0 (ideally latest 1.27.1) to cover all known CVEs.
5. **No known supply-chain or build-integrity issues** from public evidence. Published via Apache's Maven Central release process with PGP signatures.
