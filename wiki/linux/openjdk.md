## Known Vulnerabilities

Scope of this pass: every CVE dated 2026 that an Amazon Corretto changelog lists as fixed. Corretto is a downstream OpenJDK build, and each Corretto release names the upstream OpenJDK build it imports (for example "Updates Corretto baseline to OpenJDK 21.0.13.1+2"), so the "Fixed in" column gives that **upstream OpenJDK build** per release train, which is also the build other OpenJDK distributors (Temurin, distro packages) take. Where a Corretto release did not name its baseline (the 2026-10-24 out-of-band release), the Corretto version is given instead. A train missing from the list was not listed as fixed in that train's changelog (it may not be affected). "Released" is the earliest Corretto release date listing the CVE. **Severity** is the GHSA label with Oracle's CVSS 3.1 base score (the same score appears in the Corretto changelog). **Component** is the OpenJDK component from the Corretto changelog. Descriptions summarize the Oracle text quoted in the GHSA record, which states exploitability and impact but not the root cause.

Excluded: Oracle-only components with no OpenJDK equivalent in the Corretto changelogs (JavaFX, Java plugin, Installation, Oracle GraalVM-only Compiler records such as CVE-2026-87286 to CVE-2026-87288, CVE-2026-83357, CVE-2026-83368, CVE-2026-83408, and JavaFX-only CVE-2026-91477). The Oracle CPU pages and openjdk.org advisories were not reachable from this environment (HTTP 403 / blocked), so they are not cited directly.

## Security Posture Notes

- **Java4Shell (CVE-2026-114938, GHSA-6g7j-4xh3-xq2q):** HotSpot compiler heap overflow (CWE-122), CVSS 3.1 8.1 (AV:N/AC:H/PR:N/UI:N). Oracle says it is difficult to exploit but reachable by an unauthenticated attacker through APIs such as a web service, with takeover as the result. Fixed in the 2026-11-17 out-of-band release (OpenJDK 17.0.21.1+2, 21.0.13.1+2, 25.0.5.1+2, 27.0.1.1+4). Corretto lists no fix for the 8 and 11 trains. A search-result summary of secondary reporting (The Hacker News, 2026-11; page not reachable from this environment) says exploitation requires servers with AVX-512 and names Jira, Jenkins and Keycloak as reachable products; that detail is not in the GHSA or Corretto text and is unverified here. The GHSA record links a CISA alert ("Critical Java vulnerability requires immediate patching", 2026-11-17), but the CVE is not in the KEV catalog as of 2026.11.23.
- **Same-day companions (2026-11-17):** nine more CVEs shipped in the same release, including CVE-2026-114939 (JGSS, 7.4), CVE-2026-114940 (JSSE, 7.4), and two more hotspot/compiler fixes (CVE-2026-114941, CVE-2026-114946).
- **October 2026 cluster:** the 2026-10-20 CPU fixed 48 CVEs, including CVE-2026-91403 (security-libs/java.security, CVSS 9.1). Four days later an out-of-band release fixed CVE-2026-114820 (also security-libs/java.security, CVSS 9.1). Both are the only Critical-labelled 2026 records.
- **Release cadence in 2026:** quarterly CPUs on 2026-01-20, 04-21, 07-21 and 10-20, plus out-of-band security releases on 2026-08-18, 10-24 and 11-17. That is three unscheduled security releases in four months, so users who patch only on the quarterly schedule fell behind three times this year.
- **Bundled libraries:** OpenJDK ships its own FreeType and Little CMS copies on some platforms; CVE-2026-23865 (FreeType) and CVE-2026-41254 (lcms2) reached OpenJDK that way. Distro builds that link the system libraries need those packages updated too.
- **Applicability to non-Oracle builds:** the GHSA text names Oracle products only. OpenJDK applicability here rests on each CVE appearing in a Corretto changelog. For Java4Shell, the GHSA record also links Ubuntu and Red Hat CVE pages.

## Dependencies of Note

- Bundled FreeType (CVE-2026-23865) and Little CMS (CVE-2026-41254).
- Java application servers and frameworks that expose deserialization or scripting surfaces sit on top of the JDK; see [[maven/index]] for library-level pages such as Apache Axis.
