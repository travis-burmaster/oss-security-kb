## Security Posture Notes

- **2026-11-19 release (PHP 8.5.13, 8.4.28, 8.3.37, 8.2.36):** 18 CVEs. Three changelog titles say "can lead to remote code execution": the session serializer mismatch (CVE-2026-115560), partially overwritten session files (CVE-2026-126714) and the timezone cache use-after-free (CVE-2026-129496); a fourth, magic method backtraces (CVE-2026-129474), affects 8.5 only. PHP-FPM has three fixes (request smuggling, epoll use-after-free with local privilege escalation, status-page XSS), and PHP-CGI has an out-of-bounds read/write in PATH_INFO correction (CVE-2026-129538). Secondary coverage (Aikido, SecurityOnline; not verified against a PHP advisory) says CVE-2026-115560 needs an application that switches its session serializer at runtime, and suggests `session.upload_progress.enabled=0` as a mitigation.
- **PHP2Shell (CVE-2026-109618, CVE-2026-109619):** fixed 2026-10-21/22 in 8.5.12, 8.4.27, 8.3.36, 8.2.35. Both were added to the CISA KEV catalog on 2026-10-26, so active exploitation is confirmed. Anyone still running a release older than these needs to upgrade first.
- **Branch support:** the 8.2 branch is security-fix only. Several 2026 fixes appear only in the 8.5 changelog (bundled uriparser updates, the RFC 3986 URI serializer fix, magic method backtrace UAF), consistent with the URI extension being new in 8.5.
- **Bundled libraries:** PHP ships its own copies of uriparser, lexbor, libgd and (on 8.2) PCRE2, so CVEs in those libraries reach PHP through bundled-library upgrades. Distro builds that link system libraries instead need the system packages updated separately.
- **Patch cadence:** monthly releases across all supported branches; 2026 security releases landed in May, June, July, September, October and November.

## Dependencies of Note

- Bundled uriparser (CVE-2026-42371, CVE-2026-44927, CVE-2026-44928, CVE-2026-48841), lexbor (CVE-2026-29078, CVE-2026-29079), libgd (CVE-2026-9672) and PCRE2 10.40 on 8.2 (seven GHSA fixes).
- OpenSSL (PHP's openssl extension; CVE-2026-91767, CVE-2026-91769 are PHP-side TLS verification bugs, not OpenSSL bugs). See [[linux/openssl]].
