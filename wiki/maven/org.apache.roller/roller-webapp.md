## Security Posture Notes

- **Act now on CVE-2026-129448 (CISA KEV, added 2026-11-20).** Apache reissued the XML-RPC deserialization bug first published as CVE-2026-82384 (2026-09-28, "6.1.5 only") to cover 4.0.0 through 6.1.4, and the CVE record says it "is being actively exploited." Any Roller release from 4.0.0 to 6.1.5 is exposed without authentication. Apache's fix is 6.1.6 or later; 6.1.7 also fixes the 16 issues published 2026-11-11, including a second Critical deserialization path in the outbound weblog-update ping client (CVE-2026-123374).
- The CVE-2026-129448 record gives a workaround for sites that cannot upgrade: set `enabledForExtensions` to `false` in `WEB-INF/web.xml`, or remove the `/roller-services/xmlrpc` servlet mapping, then restart. Turning XML-RPC off in the admin UI does **not** help, because older releases deserialize the request before checking that setting. CVE-2018-17198 had the same "disabled in the UI but still parsed" property.
- Three 2026 batches: 17 advisories against 6.1.5 (published 2026-09-28, fixed in 6.1.6), 16 against 4.0 through 6.1.6 (published 2026-11-11, fixed in 6.1.7), and the KEV reissue on 2026-11-17. CVE-2026-111824 is an incomplete fix for CVE-2026-82387 (media upload XSS) shipped in 6.1.6.
- Recurring classes: XML parsing with external entities enabled (CVE-2014-0030, CVE-2018-17198, CVE-2026-82376, CVE-2026-82386, CVE-2026-105153), deserialization in XML-RPC (CVE-2026-82384/129448, CVE-2026-123374), CSRF gaps (CVE-2012-2380, CVE-2024-46911, CVE-2026-82380, CVE-2026-105154, CVE-2026-118411), and cross-weblog authorization in multi-user sites.
- Many 2026 records note Roller treats weblog administrators as untrusted. Single-author installs face less risk from the authenticated issues, but the unauthenticated ones (CVE-2026-129448, CVE-2026-82383, CVE-2026-82378, CVE-2026-118411 via CSRF) apply to every install.
- All Roller GHSA records sit under `advisories/unreviewed/` with no Maven package, so SCA tools that match on coordinates will not flag a Roller WAR. Inventory Roller deployments by product, not by dependency scan.

## Dependencies of Note

- XML-RPC handling uses Apache XML-RPC with vendor extensions; the 2026 fixes disable the extension types (per CVE-2026-82384 / CVE-2026-129448).
- Template rendering uses Apache Velocity; CVE-2015-0249 and CVE-2026-82385 / CVE-2026-105152 are template-driven.
