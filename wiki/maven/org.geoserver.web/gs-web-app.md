## Security Posture Notes

- **Four GeoServer CVEs are on CISA KEV:** CVE-2024-36401 (property-name XPath evaluation RCE, added 2024-07-15), CVE-2025-58360 (WMS GetMap XXE, added 2025-12-11), and CVE-2026-120705 and CVE-2026-129243 (added 2026-11-27, due 2026-11-30). KEV also lists jai-ext CVE-2022-24816 under GeoServer (see Dependencies). KEV records ransomware use as "Unknown" for all of them.
- **The November 2026 KEV pair is part of a five-step unauthenticated RCE chain** that GeoServer describes: path disclosure (CVE-2026-129244), service-rule bypass (CVE-2026-129243), GetFeatureById XML injection (CVE-2026-120705), remember-me key forgery (CVE-2026-129245), then JDBC user/role service deserialization (CVE-2026-129242). All five are fixed in 3.0.2; 2.28.6 and 2.27.7 list four of them (not CVE-2026-129245).
- **Scanner blind spot:** none of the 17 October 2026 advisories, nor CVE-2026-76904, CVE-2025-53607 or CVE-2024-35233, had a GitHub Advisory Database record on 2026-11-28, so dependency scanners that rely on GHSA or OSV will not flag them yet. GeoServer artifacts are also not on Maven Central.
- **Release model:** GeoServer keeps a stable (3.0.x) and a maintenance (2.28.x) series; the 2.27.x security releases are stopgaps for an end-of-life series. Upstream advises upgrading at least once a year.
- **Java runtime:** on 2026-11-18 GeoServer published a mitigation for the OpenJDK Java4Shell bug (CVE-2026-114938): start the JVM with `-XX:-UseBASE64Intrinsics`. See [[linux/openjdk]].
- GeoServer updated its security policy in September 2026 to require a working reproduction for AI-assisted reports.

## Dependencies of Note

- **GeoTools** (`org.geotools:*`): CVE-2024-36401 comes from GeoTools XPath evaluation (see [[maven/org.geotools/gt-complex]], CVE-2024-36404); CVE-2026-76904 is GeoTools GHSA-mqjf-5f49-2fjh in `org.geotools.jdbc:gt-jdbc-postgis` (fixed 35.1, 34.5, 33.6); GHSA-826p-4gcg-35vw is a Critical XXE in `gt-xsd-core` / `gt-wfs-ng` (fixed 33.1, 32.3, 31.7, 28.6.1).
- **jai-ext Jiffle** (`it.geosolutions.jaiext.jiffle:jt-jiffle`): CVE-2022-24816 / GHSA-v92f-jx6p-73rx, Critical code injection, fixed 1.1.22; on CISA KEV since 2024-06-26 under GeoServer.
- **GeoWebCache**: bundled; CVE-2026-120710 and CVE-2023-5786 are GeoWebCache issues.
