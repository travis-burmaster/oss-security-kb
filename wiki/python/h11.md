## Security Posture Notes

- h11 is a small but high-blast-radius HTTP/1.1 protocol parser because it is used directly or transitively by Python web servers, clients, and protocol stacks such as ASGI / HTTP tooling.
- The current public advisory footprint is compact: this review found one OSV / GHSA / CVE record, fixed in the latest PyPI release observed during the review (`0.16.0`).
- The known issue is a protocol parser disagreement class. Operators should be especially careful where h11-based components sit behind reverse proxies, load balancers, or other HTTP parsers with different malformed-body handling.
- This review did not perform active vulnerability hunting, exploit validation, or live target testing. It only normalized already-public advisory, CVE, upstream commit, package, and release metadata.

## Dependencies of Note

- h11 is intentionally a bring-your-own-I/O HTTP/1.1 state machine. Security posture depends on the surrounding server/client stack, proxy topology, timeout handling, and request-size limits.
- Consumers should inventory h11 both as a direct dependency and as a transitive dependency of ASGI servers, HTTP clients, test clients, and framework tooling.
