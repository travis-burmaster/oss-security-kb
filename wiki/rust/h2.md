## Security Posture Notes

- `h2` is a foundational Rust HTTP/2 implementation with very large transitive reach: crates.io metadata in this review showed ~576M total downloads and ~117M recent downloads.
- The public advisory set is compact but coherent. All confirmed records in this pass are **HTTP/2 denial-of-service / resource-exhaustion** issues rather than memory corruption or code execution.
- Two maintained version lines matter for downstream triage. OSV / RustSec report fixes on the 0.3.x line through `0.3.26` and on the 0.4.x line through `0.4.4` for the later advisories.
- The CONTINUATION-flood advisory should be interpreted in the broader HTTP/2 ecosystem context: risk depends on whether untrusted peers can speak HTTP/2 to a service using this crate, and on surrounding gateway / proxy limits.
- Because `h2` is commonly inherited through higher-level Rust web clients and servers, lockfile review is often more useful than checking only direct dependencies.
- No active vulnerability hunting was performed in this pass; the page records only already-published public advisory and maintainer evidence.

## Dependencies of Note

- `h2` commonly appears beneath higher-level HTTP stacks such as `hyper`, `reqwest`, and framework/server integrations.
- Runtime and resource-limit posture can also depend on adjacent crates and deployment settings, including Tokio runtime configuration, gateway request limits, and HTTP/2 enablement at the edge.
